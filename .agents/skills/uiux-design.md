# UI/UX 设计技能

> 触发：设计类需求（BR1）开工前与交付前读取；非设计类需求不加载。
> 报告骨架与禁写清单单源在 @.agents/checklists/deliverable-docs.md §九，本技能只给**逐项要点与判据**。

## 一、设计报告骨架（9 项，缺项写「不适用 + 一行理由」）

1. **信息架构** —— 页面/区块层级（≤3 层）、每层的用户目标一句话；导航与入口位置。
2. **流程** —— 主路径 + 异常路径（失败/空/无权限），每步给触发点与系统反馈；用编号步骤，不画流程图依赖。
3. **视觉规范** —— 层级（标题/正文/辅助）、间距节奏（4 或 8 的倍数）、圆角/描边/阴影档位；每项给数值，不给「大概/略微」。
4. **token** —— 颜色（语义名 → 亮/暗两值）、字阶、间距、圆角、层级 z-index；命名用语义（`surface-raised`），不用色相（`gray-200`）。
5. **状态** —— 空 / 加载 / 部分成功 / 错误 / 无权限 / 极值（超长、0 条、1 万条）；每态给可见信息与可执行动作。
6. **断点** —— ≥3 档（窄 / 中 / 宽），每档给布局变化与首个被折叠的内容；窄档优先级 = 主任务可完成。
7. **可用性** —— 关键路径点击数、防误操作（二次确认 / 撤销）、反馈时限（≤100ms 响应、≤1s 骨架屏、>1s 进度）。
8. **无障碍** —— 对比度（正文 ≥4.5:1、大字 ≥3:1）、键盘可达（焦点顺序 + 可见 focus）、语义与标签、命中区 ≥44×44、动效可关。
9. **降级产物** —— 本次实际交付的档位与内容（§二），无原型工具时**必填**。

- 报告 ≤80 行；`docs/designs/<编号>-<slug>.md`；每项结论能对到 **AC 编号**。
- **图源信息（用绘图类 MCP 出图时；未用则不触发）**：文件 id（可追溯标识，**不是 URL**）· 文件内页名 · 画板名与尺寸（如 `Home / 1440×900`）· 图层命名规则（`section/name`）；不适用项写「不适用 + 理由」。必要时导出 PNG/SVG 到 `docs/designs/assets/<编号>/` 并在报告写相对路径，凭证走本机配置。缺任一项 = 交付未完成（纪律在 @.agents/prompts/uiux-designer.md §三）。
- 上线后设计稿与实现漂移的处置：设计产物问题回本角色改报告，实现偏差回 `rd-fe`/`rd-be`；不互相顶替。

## 二、降级阶梯（BR4，按序取一，交付即成立）

- **① 结构化文字规格**（默认）—— 按 §一 1/3/4/5/6 全量给数值与判定条件，可直接照着实现。
- **② ASCII 线框** —— 单屏 ≤40 列 × ≤20 行，等宽字体可读；区块标 `[A]`、热点标 `①`，图下 3 行内说明热点行为。
- **③ 分步作图指令** —— 画板尺寸（如 1440×900）、图层命名（`section/name`）、组件与变量命名（token 同名），每步一行、可照做复现。
- **选择判据**：有原型工具就至少产出 ①+③；无工具时 ① 已成立，②/③ 视复杂度补足即可**停**，不追求完美。
- **回执措辞**：写「交付档位 ①（无 MCP/实例，按 BR4 降级）」——**不得**写成「因缺工具阻塞」。

## 三、Penpot 操作口径（本期未接入 · T540）

- 现状：客户端未接入 MCP；本技能**只给占位口径**，不写实例 URL / token / 凭证（严禁从本机配置抄入仓）。
- 接入后的最小口径：报告里留 **帧链接 + 要点摘录（≤5 行）**，断链仍可追溯；凭证走本机配置，不入仓、不入报告。
- 断链/离线时必须回落 §二 降级阶梯，**不阻塞交付**；工具接入不改变闸门（BR2 / BR2a）。

## 四、可用性与无障碍基线（默认值，可被项目基线覆盖）

- 主任务在**主路径 ≤3 次点击**内完成；破坏性操作必须有二次确认或撤销。
- 对比度：正文 ≥4.5:1、大字/图标 ≥3:1；**不用颜色单独承载语义**（配图标或文字）。
- 键盘：全部可交互元素可 Tab 达、focus 可见、顺序符合阅读；弹层焦点陷阱 + Esc 关闭。
- 命中区 ≥44×44；表单错误就近提示 + 明确下一步；空态给「为什么空 + 怎么开始」。
- 动效可用「减少动效」关闭；不做 >400ms 的阻塞式过渡。

## 五、反 AI 味清单（出现即改）

- 满屏渐变 + 玻璃拟态 + 超大圆角 + 紫色发光，任意产品可套 ⇒ 换成有理由的中性底 + 一处强调色。
- 标题用 emoji 当图标、正文用「🚀 一站式赋能」式空话 ⇒ 换成具体对象与动作。
- 每个区块都是等宽卡片瀑布 ⇒ 按任务优先级给主次，允许主区块更大、留白更多。
- 占位插画/假头像/假数据撑场面 ⇒ 空态给真实引导，不做装饰性填充。
- 字阶只差 1–2px 的「差不多」层级 ⇒ 层级差距拉大到肉眼可辨（建议 ≥1.25 倍）。
- 深色模式「反色了事」⇒ 单独定 token（降低饱和、提高层级亮度差）。
