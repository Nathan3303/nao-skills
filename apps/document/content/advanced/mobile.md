# 手机上看舰队

这套舰队平时跑在桌面电脑的 Herdr 桌面端上。装了手机端之后，你在外面也能看到谁在忙、谁在等你，并且直接在它的终端里回话 —— 手机上打开的就是桌面上那个真终端，不是镜像。

## 它是怎么连的

手机直接连上电脑上的 **herdr-core**（Herdr 桌面端的运行时），走的是 **SSH**：

- 没有 Herdr 账号，也没有任何中转服务器 —— 数据和你的电脑直连
- 手机端第一次配对会自己生成一对 SSH 密钥，把公钥加到电脑上一次即可
- 如果你的电脑已经在 Tailscale（或兼容 Tailscale 的组网工具，比如 xEdge）里，用 **Tailscale SSH** 可以跳过加公钥这一步

**前提**：

- 电脑上装着 Herdr 桌面端（`herdr-core` 0.1.14 或更高；桌面端的「Phone」面板提供配对二维码）
- 电脑的 SSH 可达（`sshd` 在跑），或者启用 Tailscale SSH
- 手机和电脑在同一个组网里（Tailscale / xEdge 都行）

## 一次性配对

1. 桌面端打开 **Phone** 面板，显示一个二维码
2. 手机端扫这个码，然后电脑上点 **Allow**
3. 连上之后，Herdr 会把这台电脑已知的其它机器也列出来（`hc` 里加过的机器、`~/.ssh/config` 里的主机、以及组网里的设备）

没有桌面端也能配：用手机端的 **Pair from Terminal**。

## 手机上能看到什么

- **Inbox**：所有机器、所有 agent 一个列表，按「等你处理 / 已完成 / 在忙 / 空闲」排序，没读过的是蓝点
- **进终端**：点开就是在跑的那个终端，可以直接打字；键条上有 Esc、Ctrl、Tab 和方向键
- **compose**：要写长一点就打开 compose —— 写、粘贴、贴截图、加图片、语音转文字，最后作为一次粘贴送进去再回车
- **找 agent**：下拉或搜索，跳到任意机器上的任意终端；子代理挂在父 agent 下面
- **Spaces**：桌面端建的空间会出现在手机上，每个 tab 画成它那几个 pane 的小地图；可以看，也可以在里面新起终端
- **手机上看着不会改变电脑上的窗口大小**

## 这套配置现在长什么样

以下是本机实测的状态（版本与数量随升级会变，判据以命令为准）：

- `hc --version` → **0.1.22**（`herdr-core` 与 `hc` 同版本）
- Herdr 桌面端 → **0.1.16**；`herdr`（TUI）→ **0.9.5**
- `hc server status` → 一个 core 在跑，**7 个终端在线**（pm、qa、arch-designer、rd-fe、rd-infra、uiux-designer，外加一个普通 shell）
- 同一个输出里 `keeps_running_after_logout: true` —— **注销后舰队继续跑**，这是「电脑锁屏/合盖后手机还能连」的关键
- `ss -ltn` → `sshd` 在监听 22
- `tailscale status` → 组网已连接，1 个对端设备（用别的组网工具就敲它的等价命令）

## 边界（很重要，别踩）

- **手机端只连 `herdr-core`，不连 Herdr TUI**。TUI 跑自己的 server，在 TUI 里起的 agent **不会出现在手机上**（两者可以在同一台机器上并存）
- **必须在桌面端形态里跑舰队**：本仓舰队用 `NAO_TERMINAL=app` 走的就是 `herdr-core`；在 TUI 里起的会话手机看不到
- **同名角色跨仓会撞名**：`herdr-core` 的终端名字是**全局唯一**的（不等于桌面 app 的 space），两个仓各起一个 `pm` 会报 `name_taken`。跨仓同时跑请给第二个仓让号（`pm2`），归属问题见[「多项目布局」](/advanced/multi-project)
- 手机上看到的 tab 标题来自桌面端，不来自我们；要改只能改桌面端的 tab 名

## 安全

- 没有中继、没有账号、没有统计：手机和电脑之间直连（SSH over 你的组网）
- 组网侧建议把 ACL 收窄到「只有手机能连电脑的 22」；`sshd` 侧建议只允许密钥登录
- 文档里不出现任何主机名、内网地址或组网 ID —— 这些属于你自己的环境

## 排错

- **手机上连不上**：先在电脑上确认 `hc server status` 是活的、`sshd` 在监听，再从手机 ping 一下组网里的这台机器
- **连上但看不到 agent**：确认这些 agent 是**在桌面端里**起的（`NAO_TERMINAL=app`），不是 TUI
- **Inbox 里没有状态**：agent 要通过 OSC 7501 上报状态（pi 有内建支持）；不报状态的终端只在终端列表里，不进 Inbox 分类
