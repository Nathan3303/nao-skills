# 翻会话记录

角色干完活会走，但「它当时到底干了什么」有时你想回看：交付物对不上、回执含糊、或者只是想确认某件事是谁改的。

记录留在你自己机器上，一条命令就能翻。

## 记录放在哪

```
~/.local/state/nao-fleet/sessions/--<编码后的仓路径>--/
```

一个仓一个子目录，里面一天几个文件，文件名带起始时间。

**这些记录不出现在 Pi 的 `/resume` 列表里**——那个列表只留你自己的会话。要看角色的，用下面的命令。

## 怎么看

```bash
.agents/scripts/nao-fleet.sh logs rd-infra            # 摘要：你说了什么、它答了什么、用了哪些工具
.agents/scripts/nao-fleet.sh logs rd-infra --raw      # 原样全文
.agents/scripts/nao-fleet.sh logs rd-infra --list     # 只列清单：仓、日期、角色、大小、路径
.agents/scripts/nao-fleet.sh logs rd-infra --task T12 # 只看某个任务的那一段
```

默认只看**当前仓**。要看别的仓，加 `--repo <仓名>`；要看全部，`--repo all`。

第一次用建议先 `--list`：它会告诉你手上有哪些记录、各自多大、在哪，比直接刷全文省事。

## 会留多久

记录不会一直堆着：

| 这条会话怎么结束的 | 留多久 |
|---|---|
| 正常收尾（有回执） | 24 小时 |
| 异常结束（崩了、被强制中断、判不出结果） | 7 天 |

异常的那几条会在同一个目录的 `.retention.log` 里点名，写清是哪条会话、什么时候记的、为什么按异常保留。

**要长期留的东西，别指望会话记录。** 交付物、验收结论、回执才是长期档案；会话记录只是过程留痕。确实想留，就在过期前用 `--raw` 转存到你自己的地方。

## 想手动清

```bash
.agents/scripts/nao-fleet.sh logs --purge              # 清当前仓里该清的
.agents/scripts/nao-fleet.sh logs --purge --days 1     # 只留最近一天
.agents/scripts/nao-fleet.sh logs --purge --repo all   # 所有仓一起清
```

清完之后再跑一次，它会告诉你「删除 0 条」——同一条不会被删两遍。

## 为什么要单独放一个目录

以前这些记录和你的私人会话混在同一个列表里，用久了 `/resume` 全是同名条目，分不清哪个是哪个。分开之后：

- 你的 `/resume` 只剩自己的会话，干净。
- 角色的记录仍可查，但要按仓、按角色去找，不会互相干扰。
- 记录过期自动清，不需要你定期收拾。

升级前留下的老记录**不会被搬走**，也不会被删：它们还在原来的位置，你在 `/resume` 里按 `ctrl+n` 只看命名会话，用 `ctrl+d` 删掉不需要的即可。
