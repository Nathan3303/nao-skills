## 一、问题证据（**均为基线实测值，不抄报告**）

- **S1 自相矛盾**：`skills/commit.md:40` 标题写「**不经 PR 流程**」，同段正文却出现 `hotfix/<id>` + PR 快速合并（`grep -c 'hotfix/'` = 1）⇒ 读者判不出 hotfix 走不走 PR。
- **S2 ADR 无条件**：`checklists/architecture-designer.md` 的 `grep -c '不适用'` = **0**（其余清单都有该出口）；`prompts/architecture-designer.md` 把 ADR 写成评审固定产出，与用户 2026-11-14 口径「仅结构性决策才写、否则明写不需要」冲突。
- **S3 三段阶梯复写**：`grep -rn '原生入口' .agents --include=*.md` = **22 行 / 11 文件**（#118 报告记 12 处 / 10 文件 = 更窄的 pattern；两版都说明「单源声明 + 全文复写并存」）。
- **S4 三件套复写**：`grep -rn '静默工作区' .agents --include=*.md` = **7 处**，而 `common/output-format.md` 声明单源。
- **E1 卡预算无信号**：`CARD_MAX_LINES=200`，最大卡 `product-manager.md` 145 行（72.5%）；`grep -rn 'CARD_MAX_LINES' tests/ | grep -v fixtures` = **0** ⇒ 超阈值只打 `!`、无断言、无 rc。

> 数字会随改动漂移 ⇒ 本 PRD 的判据**一律以命令为准**（每条 AC 自带命令），不把上面数字当验收值。

## 二、目标指标

- 每条规则**写全处 = 1 个文件**（其余为 ≤1 行指针）；可机检：`grep -rl <定义句> .agents --include=*.md | wc -l` 逐条 ≤1。
- 卡预算**有可观测信号**：`check` 能报出各卡行数与最大占比；超阈值**有断言**（移除实现 ⇒ 必红）。
- 零运行时行为变更：`check` 的 rc 语义、warn 口径不变。

## 三、范围 / 非范围

**范围**：S1 `skills/commit.md` · S2 arch 卡 + arch 清单 · S3 三段阶梯收敛（`skills/codegraph.md` 唯一写全）· S4 三件套收敛（`common/output-format.md` 唯一写全）· E1 卡预算基线 + 断言。

**非范围**：不改 `bin/`；不改闸门语义（warn-only / rc）；不碰批次 A/B 已交付（端口径 / stash 闸 / BR7 引用纪律）；不动 `docs/` 指标与台账（PM 面）；不设卡行数硬上限（D1 已裁）。

## 四、用户场景

- **作为机制维护人**：改一条规则只改一处即可生效，不必手改 10 个文件（S3/S4）。
- **作为角色执行者**：读到 hotfix / ADR 规则时不会再遇到「标题说 A、正文说 B」（S1/S2）。
- **作为长期维护者**：卡变长时能收到信号，而不是等它长到 300 行才发现（E1）。

## 五、业务规则

- **单源优先**：同一规则只在一处写全；其余处只给指针（`@.agents/skills/<file>.md`）。
- **改卡必 bump**：改 `prompts/*.md` 必须 `version + updated` + 给 `card <role> v<N+1>` 广播文本（本仓纪律）。
- **不削弱判据**：为「单源」而删内容时，**不得**把可执行判据（命令 / 断言 / 反例）删掉 —— 只删复写。
- **断言优先于文案**：E1 的信号必须有断言，不接受「文案说会告警」。

## 六、NFRs（业务视角）

- 卡体量：本批**不得增加**任何卡的行数（净增 ≤0）；清单允许小幅调整但要写明理由。
- 可读性：指针必须指明「去哪看什么」，禁止裸链接。
- 成本：单批完成，不开长跑；不引入新工具链。

## 七、AC

- **AC1（S1）** `skills/commit.md` 白名单标题与正文同口径（择一并说明理由）；判据：`grep -n '不经 PR 流程' .agents/skills/commit.md` 与 `grep -c 'hotfix/'` 的结果与所选口径一致，且文中不再出现互斥表述。
- **AC2（S2）** arch 卡 + arch 清单：ADR 改为「**结构性决策才写**；无决策时**报告内明写「本批不需要 ADR」**」；清单补「**不适用：<理由>**」出口；判据：`grep -c '不适用' .agents/checklists/architecture-designer.md` ≥ 1，且 `grep -c '结构性决策'` ≥ 1（两文件各一）。arch 卡 **bump version + updated + 广播文本**。
- **AC3（S3）** 三段阶梯：`grep -rl '原生入口' .agents --include=*.md | wc -l` ⇒ **只有 `skills/codegraph.md` 写全**（其余为指针）；判据：写全处 = 1 文件；且各卡内该主题 ≤1 行指针。
- **AC4（S4）** 三件套（静默工作区 / HEAD / 命令+输出）定义只在 `common/output-format.md` 写全；`checklists/{qa,rd-infra}.md` 改指针；判据：`grep -rl '静默工作区' .agents --include=*.md | wc -l` = 1（定义句仅一处）。
- **AC5（E1）** 卡预算基线可观测 + 超阈值有信号：`check` 能输出卡行数/最大占比（不影响 rc）；**先红后绿** —— 新增断言在未实现时必红；`CARD_MAX_LINES` 保持 **200**（不设硬限）；判据：`grep -rn 'CARD_MAX_LINES' tests/ | grep -v fixtures | wc -l` ≥ 1，且移除信号实现 ⇒ 用例必红。
- **AC6（纪律）** 所有被改的角色卡 `version` +1、`updated` 更新，并给出广播文本（`card <role> v<N+1>` 摘要）。
- **AC7（门禁）** `check` rc=0 ×2 输出逐字一致（`files=` 变化须说明）；`npm test` **双后端** rc=0；`cases/06` golden 未破。
- **AC8（零夹带）** `git diff --numstat main...HEAD` 不含 `bin/`、`package.json`、`site/`；不碰批次 A/B 交付物（`grep` 证据）；`docs/` 仅 PM 面的台账/报告。
