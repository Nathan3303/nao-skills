# Devlogs（交付记录）

多会话/多角色协作交付的流程与结果沉淀目录。**一份需求交付闭环 = 一个 dated devlog 文件**，可追溯、可复盘、可作模板。

## 约定

- **命名**：`YYYY-MM-DD-<简短主题>.md`（日期取交付终签日）
- **结构**：场景与角色 → 需求阶段（澄清/PRD）→ 委托落地 → 测试 → 修补闭环 → 终签归档 → 资产清单 → 复盘要点
- **只记事实与结论**：决策、裁决（打回/接受）、commit、测试数字、遗留项必须留痕；不写过程流水
- 外部资产（测试报告/截图/归档）记录**路径引用**，不复制正文
