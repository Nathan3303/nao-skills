## 本次更新

**这一版没有面向使用者的功能变化。** 它修的是我们自己写发布说明时的两个毛病，以及一批台账口径。

第一个毛病：v0.20.4 的发布说明在 npm 还在上传的路上就写了「已重发并核验」，被人复核对不上。这一版把顺序写死——**先写「待核验」，发布后按唯一判据实测（`dist-tags.latest` 等于该版本 + `dist.integrity` 与本地 `npm pack` 的 tarball 逐字节一致），再回填实测值**。而且这条约束同时落在三个地方（硬约束、发布前核对清单、红线），不管你从哪一步开始打勾都会撞上它。

第二个毛病：发布说明模板与真实写法长得不一样。模板的第一行是段标题，而实际发布的说明第一行是版本标题、状态行夹在版本标题和段标题之间。照模板抄的人会把状态行写成「本次更新」段的第一行。这一版把模板改成与实际完全同一形态。

## ⚠️ 请留意

- **发布说明的形态变了**：文件第一行现在是版本标题（`# vX.Y.Z — 一句话`），状态行紧随其后，原来的「本次更新」降为二级标题。
- **可能看到「待核验」**：某个版本的 Release 正文若显示状态为「待核验」，表示 npm 那一步还没完成核验（通常是发布当天、回填前）。
- **不影响任何命令**：`ensure` / `status` / `close` / `check` 的行为与输出一个字都没改。
