# v0.20.0 — 代码定位升级：角色先查代码图谱，查不到自动退回

- 状态：已发布（v0.20.0 · tag + Release 已发；**npm 已重发并核验**：`latest` = 0.20.0、`dist.integrity` 与本地 tarball 逐字节一致）· 更新：2026-10-28 · Owner：PM

## 本次更新

这一版把「找一个功能在哪、改这里会牵扯谁」从**一条条搜索 + 翻文件**改成**先问代码图谱**。装了 codegraph（一个本地代码索引工具）之后，角色在会话里能直接调用图谱工具，一次拿到相关源码和调用链影响面；没装、或这个仓库还没建索引，就自动退回命令行工具、再退回搜索 —— **不装也能照旧干活，装了就少翻文件**。

## ✨ 更好用了

- **少翻文件，多看结构**：问「这段是怎么实现的」「改这个会影响到谁」时，可以一次拿到相关源码 + 影响面，而不是开十几个文件逐个读。
- **体检会说清「为什么用不上」**：`check` 会明确落到四种状态之一 —— 插件没装 / 装了但缺命令行工具 / 工具就绪但仓库没建索引 / 齐备；缺哪一步、补哪条命令，都写在同一行里。
- **装不装都不挡路**：以上任何状态都不会让体检失败（退出码仍为 0），也不会阻塞拉起角色会话。
- **角色口径统一**：六个角色与验收清单都改成同一句「先图谱 → 再命令行 → 最后搜索 + 只读需要的行」，不再各写各的命令。

## ⚠️ 请留意

- **装了插件 ≠ 生效**：还需要命令行工具 + 每个仓库各自建一次索引。索引没建时插件会静默不激活，只有体检那行会告诉你。
- **索引过期不再算故障**：以前「索引有未同步改动」会让体检失败，现在只提示（`-v` 看详情与同步命令）—— 编辑一个文件就会过期，把正常工作态当红灯会让人逐渐忽略体检。
- **默认体检输出从 1 行变 2 行**：摘要行 + 代码图谱状态行。
- **资源**：每个有索引的仓库会常驻一个后台索引服务（本机约 130MB），每个同时开着的角色再多约 70MB；本机实测 6 个角色合计约 550MB。仓库多、内存紧就只给常用仓库建索引。
- **仓库里可能多一个自动生成的小文件**（`.pi/APPEND_SYSTEM.md`）：已进忽略清单、不会进提交，由插件自己创建与回收，我们不代管。
- **会话外跑 `pi` 命令建议换目录**：在有索引的仓库里跑 `pi list` 这类命令会留下一个后台服务（每仓最多一个，不会无限增长）。规避办法是 `( cd /tmp && pi list )`；已经留下的可用 `codegraph daemons` 手工停。
- **插件注入的英文说明在这套机制里不生效**：所以定位口径统一由角色卡与技能承载，不依赖插件自带的提示。
