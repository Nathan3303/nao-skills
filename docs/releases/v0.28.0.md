## 一句话概括

**只剩一个终端后端：herdr。** 旧的 tmux 后端整层删掉了——如果你（或 CI）还在 `export NAO_TERMINAL=tmux`，升级后第一次跑会**明确报错并告诉你怎么办**，不会悄悄换后端。

## ⚠️ 请留意（本版有破坏性变更）

- **不再支持 tmux**。设置 `NAO_TERMINAL=tmux`（或任何非 `herdr` 的值）后跑任何舰队命令，都会**立刻停下并返回码 2**，附一行提示：tmux 后端已移除、请去掉该变量。
- **`cleanup -S <socket>` 没了**：改成 `cleanup --session <名>`。老脚本里的 `-S` 同样会**停下并告诉你新写法**。
- **布局变量与「tmux 布局」体检节删除**：`NAO_TMUX_LAYOUT` / `NAO_TMUX_MAIN_WIDTH` / `NAO_TMUX_MIN_PANE_WIDTH` 不再有任何效果（设置也不会报错，只是被忽略），`check` 里也不会再出现那一节。herdr 下「1 仓 = 1 workspace、1 角色 = 1 tab」，窗口太窄请把窗口/显示器换大或调整 herdr 的 `[server] headless_cols/headless_rows`，不再有「切布局」这条路。
- **还没准备好换？** 把机制版本 pin 回去即可继续用 tmux：`pi install -l npm:@nathan33/nao-skill@0.27.0`。
- **说好的「至少保留 2 个 MINOR / 90 天」没有做到（诚实交代）**：上一版文档承诺 tmux 回退会保留 ≥2 个 MINOR 且 ≥90 天、移除前先发弃用说明；这次是仓主在评估后**明确要求直接移除**（旧后端形态与新的「每仓一个 workspace、会话名不带 `@`」模型冲突，留着等于两套语义并行）。补偿措施 = 移除做成 **fail loud + 一行迁移指路 + 可 pin 回旧版**，而不是静默坏掉。

## ✨ 更好用了

- **报错指路更准**：所有「需要 herdr」类提示不再劝你「切回 tmux」（那条路已经不存在），改为「装 herdr / 在 herdr 的 pane 内重试」，并说明旧版还能怎么拿。
- **体检更快更少噪音**：`check` 少了一整节 tmux 布局检查；会话隔离/回收这类真正在用的检查一条没少。

## 📦 更小更快

- 舰队脚本体积 **5482 → 4531 行（−17.4%）**，函数数 **163 → 131**：删掉的全是 tmux 专有实现（pane 定位、回收、布局几何、窄列回退、宿主窗口寻址），herdr 侧实现一行未改。
- 测试编排去掉双后端跑法：不再是「同一套用例跑两遍后端」，全量跑一轮即可。
