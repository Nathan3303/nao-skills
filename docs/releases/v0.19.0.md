# v0.19.0 — 舰队只支持「tmux 内 + pi ≥ 1.4.0」

- 状态：待发布（v0.19.0 · 破坏性变更）· 更新：2026-10-27 · Owner：PM

## 本次更新

这一版把舰队的运行方式收成**一条路**：**必须在 tmux 会话里用**，并且 **pi 版本 ≥ 1.4.0**。以前「不在 tmux 也能开窗」「后台跑」「screen 兜底」这些备选，实际维护成本高、没人真用——它们在最近几个批次里反复制造「明明在跑却查不到」的补丁。收掉之后，舰队只有一种起法、一种收法。

## ✨ 更好用了

- **一条路，不再猜**：`ensure` / `status` / `close` 都只认「tmux 会话内」，句柄一定存在；`close` 不再有「无法确认在线状态」这类不确定结论。
- **前提不满足就立刻停**：非 tmux 环境直接报错退出（`exit 3`）+ 一行提示（`tmux new -s nao`），**不建任何窗口 / 会话 / 锁**，不留半启动现场。
- **体检多了一道硬门**：`check` 同时断言 `tmux` 可用与 `pi ≥ 1.4.0`；版本不够会指名当前版本，并把其余体检跑完（一次看全）。

## ⚠️ 请留意（破坏性变更）

- **必须 tmux + pi ≥ 1.4.0**：非 tmux 环境里 `ensure` / `status` / `close` 一律报错退出（实验场清理 `cleanup -S <socket>` 除外——它本来就该在 tmux 外跑）。
- **迁移①**：先进 tmux 再跑舰队——`tmux new -s nao`，然后在这个会话里照旧 `bash .agents/scripts/nao-fleet.sh ensure ...`。
- **迁移②**：**旧版用 `--background` / screen 拉起过的会话，本版看不到也收不回**——先 `screen -ls` 手工清理一次，避免后台残留。
- **老配置可以删了**：`NAO_TERMINAL` 与 `--background` 不再有任何效果（脚本已不解析）；tmux 布局变量 `NAO_TMUX_*` 不受影响。
