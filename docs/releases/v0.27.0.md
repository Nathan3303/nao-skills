## 一句话概括

**「舰队」不再是个名字，而是「一个仓 + 一个 workspace + 一个 pm」这套东西：会话名短了（`pm` / `qa(T554)`），在哪个 herdr 会话里都能直接拉起，重名自动加数字。**

## ⚠️ 升级前先看一眼（本版有破坏性变更）

- **会话名不再带 `@<舰队>`**：常驻是 `pm`、`rd-be`；派生是 `qa(T554)`、`arch-designer(T554)`。**重名自动加数字**：`pm2`、`qa2(T554)`（最多到 `9`，占满就报错并让你先清理）。
- **`--fleet` / `--scope` / `.agents/fleet-scope` 弃用**：仍能传，但只打**一行提示**然后被忽略（本版不校验、不报错），**下一版移除**。
- **升级前已经在跑的旧会话不会失联**：名字里带 `@` 的老会话仍能被 `status` 看到、被 `close` 回收。

## ✨ 更好用了

- **不再挑 session**：以前在 herdr 的 `default` 会话里 `ensure` 会被**直接拒绝**（`exit 3`）；现在 `ensure` / `status` / `close` 在任何 herdr 会话里都能用。
- **一个 workspace 就是一个仓**：`ensure` 会把 workspace 标签设成**仓名**，pane 就在那个仓里；同一 workspace 里再加角色只是**加 tab**，不会另开窗口区。
- **一个 workspace 一个 pm**：pm 和它派的 worker 都是同一个 workspace 里的 tab；跨仓协作由各仓的 pm 之间互相对话。
- **`.agents/fleet.yaml` 瘦身**：只保留「仓代号 → 路径」映射（`slug` 退役），用来支持 `ensure rd-be@api` 这种写法；`@` 只选目标仓，**不再进名字**。

## ⚠️ 请留意

- **`cleanup` 对 `default` 会话是「两步走」**：先打印「将停止哪个 session、影响几个 workspace / 几个 pane」，**加 `--force` 才真执行**；不加则零动作（rc=2）。这是刻意的 —— 停掉 default server 会把你自己的所有窗口一起关掉，不可逆。
- **`--fleet` 打架不再报错**：本版一律「提示 + 忽略」，所以如果你依赖旧版「fleet 冲突就失败」的行为，需要自己看那一行提示。
- **tmux 回退仍然可用**（下一版才移除）；本版两后端门禁都是绿的。
