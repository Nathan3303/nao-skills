# v0.18.4 — 会话内子代理也守舰队的回执纪律

- 状态：已发布（v0.18.4 · tag + Release 已发；npm 重发由用户执行后核验）· 更新：2026-10-14 · Owner：PM

## 本次更新

这一版给「在会话内派子代理干活」补上了统一口径：子代理交回的只是**证据**，正式回执仍由父角色发出；子代理不得冒充舰队角色、也不得直接给 PM 发「完成」消息；需要拍板时通过父角色通道询问。想要这份口径生效，按仓库里的安装说明把一段 Markdown 模板复制到你的配置目录即可（本版**不会**自动改你的配置）。

## ✨ 更好用了

- **子代理协作口径可一键继承**：仓库新增 nao 版子代理注入模板，附同目录安装说明（一条复制命令 + 一段相对路径配置）。装好后，会话内子代理会自动带上舰队口径 —— 结果只作证据、不冒用舰队身份、证据按统一格式给。
- **出问题有明确入口**：安装说明给出排障入口 `/subagents-doctor`，能直接看到子代理协作桥是否启用、以何种模式生效，以及当前模板有没有被读到。

## ⚠️ 请留意

- **需要你手动安装一次**：本版只在仓库里提供模板与安装说明，**不会**替你写任何用户配置文件；不安装时行为与之前完全一致。
- **子代理消息不再被当成回执**：即使子代理说「我做完了」，也不会被当作对 PM 的交付；父角色仍要自己核对并发正式回执。子代理也不应再给你或 PM 发`完成`形态的消息。
- **长跑子代理的已知低危行为**：会话内子代理跑得久时，偶尔会在父会话里留下一条控制提示（只占一点上下文，不会出现在会话列表里）。本版只记录、不调整。
