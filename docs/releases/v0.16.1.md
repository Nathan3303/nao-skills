# v0.16.1 — 规则手册更一致 + 界面验收交给你

- 状态：已发布 · 更新：2026-10-13 · Owner：PM

## 一句话

舰队各角色的「规则手册」一次收敛（写需求、写代码、验收的口径统一）；以后涉及界面的改动，会给你一份**照着做就行的验收清单**，由你亲自看界面，不再用机器人替你判断好不好看。

## 🔧 规则更一致了

- **写需求**：PRD 的九个模块统一用「小标题 + 列表」承载，不再出现同一份文档两种写法互相打架的情况。
- **写代码/测试**：前端、后端、测试、架构四个角色的「完整红线清单」补齐了此前只在角色卡上写着、清单里漏掉的条目（跑全量检查并报准数字、定位代码、评审要回执、决策要落档）。
- **任务回执**：每份完成回报都带提交编号，验收时能一眼对上代码，不用来回猜。

## ✨ 更好用了：界面验收交给你

- 涉及界面的改动，测试角色不再用无头浏览器 / 截图对比自动「看」界面——改为给你一份**用户验收清单**。
- 清单里每一项都写清三件事：**测什么 · 怎么操作 · 预期看到什么**，你照着点一遍、勾个「通过 / 不通过」就行。
- 覆盖范围：界面风格是否统一、加载 / 空 / 错误 / 成功四种状态、不同屏宽、键盘操作、对比度、动效偏好，以及「一眼看上去像不像模板批量生成」。
- 功能与交互的自动化测试照旧保留，不受影响。

## ⚠️ 请留意

- 涉及界面验收的需求，交付时会附上清单；你不在场时清单会留在项目 `docs/reports/` 下，方便自取。
- 本次只对**以后新写**的文档生效，不会去重排历史文档。
