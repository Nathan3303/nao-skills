# 本次更新

**这一版把舰队的会话处理做「准」了：修掉一个会误伤同类会话的缺陷 —— 前台显示某个角色已离线时，`close` 却可能把它的同名任务派生会话悄悄回收掉，还谎报成功。同时新增实验场安全清理入口，避免清理实验用 tmux 时连坐真实服务器。**

## 🐛 修复了

- **会话名精确锚定（tmux 与 screen 双宿主）**：`status` / `close` 不再把 `nao-<角色>` 与任务派生的 `nao-<角色>-<任务>` 混为一谈。
  - 常驻会话精确缺席、只有同名派生会话在场时，`close <常驻名>` 现在**非 0 退出并给出诊断与出路**（要回收派生请用派生名，要拉起常驻请用 `ensure`），不再静默误杀派生并谎报「已回收」。
  - `status` 不再把派生会话计为常驻在线。
- **既有能力零回退**：精确常驻回收、派生显式回收（`close --task <任务> <别名>`）行为不变；`ensure` 的拉起/attach 行为与 0.14.0 保持一致。

## 🛡️ 新增

- **实验场安全清理入口**：`nao-fleet.sh cleanup -S <socket>`
  - **强制显式指定**隔离 socket；不带 `-S`、或指向生产默认 socket，一律 **exit 2 单行拒绝**，真实 server 不受影响。
  - 生产默认 socket 的判定**不依赖 `TMUX_TMPDIR`**（修掉一次因夹具设 `TMUX_TMPDIR` 而放行、导致真 server 连坐的事故），并对 `//`、符号链接等路径做归一化；无 server 的陈旧 socket 幂等清理。
  - 用法与纪律已写入 `--help` 与技能文档。

## ⚠️ 使用纪律（新增了两条）

- 实验 / 夹具一律 `env -u TMUX` + `-S <隔离 socket>`；**不要**裸跑 `tmux kill-server` / 宽匹配 `pkill`。
- 不要在承载自己会话的 tmux 里直接跑清理或回归脚本。

## ⬆️ 升级

- 将项目 pin 升到 `0.16.0` 即可，**无需任何迁移动作**；`check`（roles=6）、`init` / `migrate` 幂等行为保持不变。
