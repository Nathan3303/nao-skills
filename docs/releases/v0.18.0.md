# v0.18.0 — 回归验证接入唯一门禁，发布前多一道严格闸门

- 状态：已发布（v0.18.0 · tag + Release 已发）· 更新：2026-10-14 · Owner：PM

## 本次更新

这版把项目自带的回归验证套件接入了唯一机械门禁，并新增发布前的严格闸门 —— 改完机制脚本后，跑一次 `npm test` 就能发现回归，不用再靠人记得单独跑套件。

## ✨ 更好用了

- **一条命令跑全量验证** —— `npm test` 现在先跑轻量静态检查，再接着跑完整回归套件；以前它只看静态检查，回归套件要另外手动跑。
- **发布前多一道严格闸门** —— 新增 `npm run test:t4:full`：要求这一次运行里**没有任何被跳过的检查**才算通过，适合作为发版前的最后确认。
- **缺环境能力会诚实标出来** —— 本机没有对应工具、或外部服务/凭据不可达时，相关检查会显式标记为「跳过」并计数，不会被悄悄当成通过。

## 🐛 修好了

- **「一个都没跑」不再显示成功** —— 以前删掉用例文件、或把用例编号传错，套件可能一个用例都没执行却仍然报成功；现在这些情况一律以非 0 退出。
- **网络/凭据抖动不再让门禁无辜变红** —— 需要真接口的检查以前遇到连不上或没凭据就判失败；现在只有「确实拿到了结果、但内容不符」才算失败，连不上或没凭据按「跳过」处理。

## ⚠️ 请留意

- **`npm test` 的含义变了** —— 从「只跑静态检查」扩为「静态检查 + 完整回归」。以前几秒就跑完，现在大约两分钟。只想快速做轻量检查，请改用 `npm run test:agents`。
- **打包 / 发布流程没有被拖慢** —— 打包前置仍然只跑轻量检查，不会为了打包去跑完整回归，也不会在打包时发起外部调用或等待网络。
- **安装到别的项目后，`npm test` 不适用** —— 回归套件不随 npm 包发布，只有在这个仓库里才能跑；在消费方项目里它因缺少套件而报错，属预期。
- **发布前需要完整环境能力** —— 发布前的严格闸门 (`npm run test:t4:full`) 要求当次运行里没有被跳过的检查；本机现具备全部能力（`strace` / `bwrap` / `tmux` / `pi` / registry），缺任一项时会非 0 退出并指名缺哪项（这是故意的：避免「跑了个半截也能过发布闸门」）。

## 技术细节（可略过）

- `package.json` scripts：`test:agents`（原 `test` 原文：`check` + `tsc`）· `test:t4` = `bash tests/t4/run.sh` · `test:t4:full` = `T4_ALLOW_MISSING=0 T4_REQUIRE_FULL=1 bash tests/t4/run.sh` · `test` = `test:agents && test:t4` · `prepack` = `test:agents`（剥离 t4）。
- 默认严格：`T4_ALLOW_MISSING` 默认由 `1` 翻为 `0`（宽松需**显式** `1`，缺 T2 产物记 BLOCKED）；`T4_REQUIRE_FULL=1` 判据 = **汇总层 SKIP 计数 + DEGRADE 计数 = 0**（SKIP 含从用例输出解析的**行首** `[SKIP]` / `SKIP:` 行，覆盖用例内子项；DEGRADE = 能力降级，**不终止用例**），NOTE 允许并计数。**full 需能力齐备（`pi` / tmux / bwrap / strace / registry 可达），能力降级即 rc≠0。**
- 汇总改白名单：仅 `PASS` / `SKIP` 视为通过；`BLOCKED` → rc 2；`MISSING` / `NOT_RUN` / 未知值 → rc 1。三类参数错误（`--case` 缺值 / `--case` 无匹配 / 裸位置参数）rc=1；`--list` / `--preflight` 行为不变。
- 用例契约守护新增静态断言（`scripts.test` 走 `test:t4` 且 `test:t4:full` 含两个严格轴、`prepack` 不含 t4、用例脚本以 `t4_exit|t4_skip|exec` 收尾）；case 02 / 07 网络面极性修正（外部不可达 / 未成功启动 / 无凭据 ⇒ SKIP/NOTE）。
- 测试基线：t4 12 用例 · **PASS 断言 267 · 0 FAIL · SKIP 0 · DEGRADE 0 · NOTE 2**（口径：删 1 条空心断言 + 新增 4 条契约断言）；**发布前置 `npm run test:t4:full` rc=0**（发布机已具备 `strace`/`bwrap`/`tmux`/`pi`/registry）· QA 独立复跑基线（当时缺 `strace`）为 **266 / DEGRADE 1**，两者差异仅 4b 一条直接证据。
- 版本：本版号 `0.18.0`（MINOR），由发布节点写入 `package.json`；npm registry 仍 `0.17.3` —— `tests/` 不入包，消费者侧 `npm test` 本就不可用，本版**默认不重发**。
