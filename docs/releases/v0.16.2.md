# v0.16.2 — 派生会话不再拆你正在用的窗口

- 状态：已发布 · 更新：2026-10-13 · Owner：PM

## 一句话

舰队拉起新会话窗口时，现在会固定落到「发起方所在的窗口」——你在别的窗口干活，不会再被打断。

## 🐛 修好了

- **修复：拉起/派生会话不再拆开你当前窗口**。之前你在别的 tmux 窗口工作时，新会话可能落到你正在用的窗口里、把你的窗口布局挤乱；现在新窗口始终建到**发起方所在窗口**，你在哪个窗口干活都不受影响。
- **附带修复：布局与窗口选项不再「泄漏」到你正在用的窗口**（此前可能被悄悄改掉窗口宽度预设）。
- 单窗口场景与之前**逐值一致**（零回归）。

## ⚠️ 请留意

- 极少数情况定位不到发起窗口（如该窗口刚被关闭）：此时该角色**不会被拉起**（跳过并打印原因），不会退回去拆你正在看的窗口；如确有必要，可用环境变量显式指定目标窗口（见技术细节）。
- 常驻角色与任务派生角色共用同一套规则。

## 技术细节（可略过）

- 实现：`resolve_host_window()` —— 显式 `NAO_TMUX_HOST_WINDOW`（可跨 session，建议 `@<id>`）> `TMUX_PANE` → `window_id` > 名册唯一命中（仅本 `$TMUX` 所属 session）> **warn + skip**（不创建、不静默、rc 不劣化）；`-t` 贯穿 split/布局/窗口选项/尺寸读取（窄列守卫按宿主窗口宽生效）
