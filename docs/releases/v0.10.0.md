# 简明版（面向用户）

- 状态：已发布 · 更新：2026-09-30 · Owner：rd-infra

**这一版：舰队对「怎么把文档写到人能看懂」立了两条通用规矩 —— 发版说明必须说人话、文档默认不用表格；所有接入 nao-skill 的仓库下次同步后自动获得。**

## ✨ 更好用了

- **发版说明有了统一写法**：以后每个仓库给用户看的更新说明，都会先给一段「面向用户的简明版」—— 用大白话讲清「这版对我有什么变化」，再把任务编号、文件名、测试数字这些内部信息挪到末尾「技术细节」。
- **行为变更会说清后果**：不再只写「改了某个按钮的状态」，而是写「点过之后按钮会变成『已撤销』且不能再点」。
- **文档默认改用列表排版**：需求、验收标准、范围等不再挤进表格；改用有序 / 无序列表 + 加粗字段名，长内容更好读，改动也更容易审阅。

## ⚠️ 请留意（这一版行为有变化）

- **从这版起，写发版说明是发版流程的固定一步**：只写内部术语、用户看不懂的说明会被打回。
- **新写的文档请默认不用表格**：确有「需要并排比较」的小规模对照才用表格，且行列要少、单元格要短。**这条只对之后新写 / 新改的文档生效，不会去大改已有文档。**
- 规范采用「引用式」：只在少数几个入口留指针，不复制全文，避免多处版本漂移。
