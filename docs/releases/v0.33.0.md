## 本次更新

**桌面版后端修好了三处，拉起会话会进你当前的工作区，会话名也简化了。**

### ✨ 更好用了

- **拉起会话时进你当前所在的工作区**：你在哪个工作区里敲命令，新会话就加在那个工作区的标签页里，不再另开一个空工作区。
- **会话名简化**：会话名就是角色名（如 `rd-infra`），任务号不再拼进名字 —— 名字更干净，也不再受各终端对名字字符的限制。

### 🐛 修好了

- **桌面版不再「闪现后消失并报放置失败」**：以前在桌面版里拉起会话，工作区刚出现就被判失败并撤回；现在一次就成。
- **会话状态列表能认出正在跑的会话**：以前桌面版里已经在跑的会话会被误报「未运行」，现在能正确显示在线。
- **带任务号的派单又能用了**：以前桌面版会拒绝带任务号的名字，现在任务号只作为元数据保存，不再影响拉起。

## ⚠️ 请留意

- **会话名格式变了**：从「角色(任务号)」变成「角色」。如果你有自己的脚本在解析旧格式，请改用 `nao-fleet.sh status --json` 里新增的 `task` 字段。
- 旧格式的会话仍能被识别和关闭（只读兼容），不会被迁移，也不需要手动处理。
- 无需改任何配置；已经拉起的旧会话可以照常使用。
