# 任务导出面板（示例 · 未实施需求）

> 本文件是 `docs/designs/` 的骨架示例：主题虚构、AC 虚构、无原型链接。真实报告须替换为 PRD 的 AC 编号。

## 一、信息架构

1. 入口：任务列表页右上「导出」按钮（一级动作，不与「新建任务」并列抢占主位）。
2. 层级：导出抽屉（选择范围 → 选择字段 → 确认）≤3 层，抽屉内不跳新页。
3. 出口：抽屉关闭保留上次选择；导出后台任务入口在「导出记录」列表。

## 二、流程

1. 主路径：点「导出」→ 抽屉默认勾选「当前筛选结果 + 常用字段」→ 点「导出」→ 抽屉收起 + 顶部进度条。
2. 异常：筛选项为空 → 抽屉内提示「当前无数据可导出」并禁用主按钮。
3. 异常：行数 > 1 万 → 转后台任务，抽屉提示「已转后台，完成后通知」。
4. 异常：无导出权限 → 按钮可见但禁用，hover 说明申请路径（不隐藏功能）。

## 三、视觉规范

- 层级：抽屉标题 16/24、字段组标题 13/20（中黑）、说明 12/18（辅助色）。
- 间距：区块间 24、表单项间 12、标签与控件间 6（4 的倍数节奏）。
- 描边：控件 1px、抽屉分隔线 1px 且仅用于分组，不叠阴影与描边。
- 主按钮唯一（右下角），次按钮「取消」为文字按钮。

## 四、token

- 颜色：`surface-raised`（抽屉底）· `border-subtle`（分隔）· `text-primary` / `text-secondary` · `accent`（主按钮，全屏唯一强调）。
- 字阶：`font-sm 12` / `font-base 14` / `font-title 16`（整数档，窄屏不缩放）。
- 间距：`space-1 4` / `space-2 8` / `space-3 12` / `space-4 24`。
- 圆角：`radius-sm 4`（控件）/ `radius-md 8`（抽屉）；层级 `z-drawer 40` / `z-toast 60`。

## 五、状态

- 空：抽屉内一行说明 + 「清空筛选」入口。
- 加载：主按钮内联 spinner，按钮宽度不变（防抖动）。
- 部分成功：后台任务完成后 toast「已导出 8/10 字段，缺字段见详情」。
- 错误：toast + 「重试」按钮，不吞掉已选配置。
- 极值：0 条 / 1 万条 / 字段名超长（截断 + 全量 tooltip）。

## 六、断点

- 宽（≥1280）：抽屉宽 480，字段两列。
- 中（768–1279）：抽屉宽 400，字段单列。
- 窄（<768）：抽屉全屏，主按钮吸底；**首个被折叠**的是「字段分组标题」的说明文字。

## 七、可用性

- 主路径 2 次点击（打开抽屉 → 导出）；常用字段已预选，减少决策。
- 后台任务转交后保留配置，可「再次导出」。
- 响应：点击 ≤100ms 反馈，≤1s 出进度条，>1s 显示百分比。

## 八、无障碍

- 对比度：正文 `text-primary` 对 `surface-raised` ≥4.5:1；禁用态 ≥3:1 且配文字说明原因。
- 键盘：抽屉开启后焦点锁在抽屉内，Esc 关闭并归还焦点到「导出」按钮。
- 语义：抽屉 `role="dialog"` + `aria-labelledby`；进度条带 `aria-valuenow`；命中区 ≥44×44。
- 动效：抽屉 200ms 进出，可被「减少动效」关闭。

## 九、降级产物

- 交付档位：**① 结构化文字规格 + ② ASCII 线框**（示例无原型工具，按 BR4 降级，不构成阻塞）。
- 线框（窄屏）：

```text
+---------------- 导出 ----------------+
| 范围  ( ) 当前筛选  ( ) 全部          |
| 字段  [x] 标题  [x] 状态  [x] 截止    |
|       [ ] 负责人  [ ] 标签            |
|        无数据时：清空筛选             |
|                        [取消] [导出]  |
+---------------------------------------+
```
