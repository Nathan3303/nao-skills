# 架构评审：T520 ADR 结构契约（骨架 / 值域 / 下沉边界）

- 状态：已定稿（技术签字 · 已回执 PM done(full)） · 更新：2026-10-14 · Owner：arch-designer
- 指针：PRD `docs/prds/2026-10-14-doc-templates-convention.md`（§三 范围 1/3/5、§五 BR1–BR7、§七 AC1–AC3）· 决策 ADR `docs/adr/2026-10-14-adr-structure-contract.md`

## 结论

**可行（技术签字）**：AC1 / AC2 / AC3 的口径可机械核验，无架构冲突；采纳 PRD 的 ≤60 行保留主张（靠下沉复位，不放宽数值）。

## 一、定稿标题清单（逐字，供 `.agents/templates/adr.md.example`）

必写 5 节（顺序即下方位次，标题逐字、不编号）：

1. `## 背景`
2. `## 决策`
3. `## 理由`
4. `## 对照过的备选模式`
5. `## 参考来源`

可选 3 节（出现时必须落在下方位次，标题逐字）：

6. `## 后果与风险`
7. `## 限制与已知边界`
8. `## 相关指针`

- 全序：`背景` → `决策` → `理由` → `对照过的备选模式` → `后果与风险` → `限制与已知边界` → `相关指针` → `参考来源`（`参考来源` 恒为末节）。
- 探针口径：必写 5 必在；`## ` 标题集合 ⊆ 上述 8 个；按上表索引单调；出现 `实施闸门` / `接线清单` / `交接` / `备选方案` 任一 = FAIL。与 AC1 对齐：探针只需断言必写 5 + `后果与风险` + `相关指针`（`.example` 已填）；第 7 项属白名单新增，见 D3。

## 二、状态值域与字段口径（第 ② 项）

- 状态值域（四值闭合）：`提议` / `已接受（待落地）` / `已接受（已落地 vX.Y.Z）` / `已废弃（被 <文件名> 取代）`。
- 头部恰 4 字段（AC1）：`状态` / `更新` / `Owner` / `指针`。
- `出具日` **不单设字段** = 文件名日期前缀（= 评审终签日，不可变）；`更新` 仅在结论变化时改。
- `落地版本` **不单设字段** = 写入 `状态` 值（落地时 `待落地` → `已落地 vX.Y.Z`，单点改）。
- 值域仅约束**新写 / 新改** ADR；历史索引行状态值不追溯（§七），故 AC3 探针**不得**对索引旧行做值域断言。

## 三、下沉边界与 ≤60 行上限（第 ③④ 项）

- **保留 ≤60 行**（与 PM 主张一致）；度量口径 = `wc -l` 全文（含头部与空行），无人工判断。
- 下沉落点：`docs/reports/<编号>-arch-review.md`；下沉项 = 实施闸门 / 接线清单 / 交接实现 / 判定式全文 / 用例集。
- 边界优先于上限：超长先下沉；探针只对新增 ADR + 模板断言 ≤60，历史 7 篇不追溯。
- 取舍：不采纳「放宽上限」「追溯改写存量」；`deliverable-docs.md` §四 的「对照模式表」应更正为「对照模式清单」（ADR 正文默认不用表格，BR6），并使 §四 节序与上表一致。
- 集成核对（已实测）：`check` 的 `files` 只统计 `.agents/**` → 本批新增 2 个 `.example` 后恰 `files=46`；本报告与首实例 ADR 落在 `docs/`，**不影响** `files`，与 AC4 无冲突。

## 四、风险

- 机械核验误伤：标题微调即 FAIL → 只校验标题 / 顺序 / 字段，不校验语义；改骨架走 ADR 修订。
- 可选节膨胀：`限制与已知边界` 与 `后果与风险` 语义相邻 → 只允许各一，按「适用范围边界 vs 决策后果/风险」二分；二者之外不放行。
- 索引存量：现「决策」列达 100 字级 → 按 BR7 收敛 ≤20 字，链接留存于「主题」列，信息不丢。

## 五、待 PM 拍板

- **D1** 值域 `已废弃（被 ADR-N 取代）`：本仓无 `ADR-N` 编号，指称悬空 → 建议 `被 <文件名> 取代`；若坚持 `ADR-N`，须先引入编号方案（本批范围外，另开批）。
- **D2** `出具日` / `落地版本` 是否单设字段：建议不设（折入文件名 / 状态值，保头部 4 字段与 AC1）；若须显式，头部变 5 字段并同步改 AC1。
- **D3** 第 7 项可选节 `限制与已知边界`：建议采纳（历史 2 篇有此节，且可挡「限制」内容漂进 `背景`）；若判多余，删该行即可，不影响 AC1–AC3。
