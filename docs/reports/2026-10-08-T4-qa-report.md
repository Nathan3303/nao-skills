## 4. 设计说明（判定口径）

- **夹具策略**：只读仓库；夹具全在临时目录；`npm pack --ignore-scripts` + `npm install --prefix .pi/npm`
  复现落盘，并由 T4-07 与真实 `pi install -l --approve` **逐文件对照**确认等价。
- **版本动态**：tarball / settings pin 均从 `package.json` 读取；T3 bump `0.12.0` 后重跑即可，断言语义不变。
- **BLOCKED 语义**：本次严格模式 `T4_ALLOW_MISSING=0`，依赖缺失即 FAIL；结果无 BLOCKED。
- **降级判据**：`exit==2` + `^DEGRADED:` 计数==1 + 可复制恢复命令（与「能跑但失败=1」区分，D5）。
