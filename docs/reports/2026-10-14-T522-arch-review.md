# T522 arch 结构评审报告：`tests/t4` 接入 `npm test` 门禁

- 状态：已定稿 · 更新：2026-10-14 · Owner：arch-designer
- 指针：PRD `docs/prds/2026-10-14-t4-gate-wiring.md` · ADR `docs/adr/2026-10-14-npm-test-gate-scope.md` · 分支 `nao/t4-gate`（PR #40）

## 一、可行性结论（输出信封）

- **有条件可行**：采纳「`test` 全量串联 + `prepack` 剥离 t4 + 默认严格」的形态；条件 = 先处理 NFR 与实现矛盾（case 02/07 网络面可假红）并改白名单修法覆盖 `NOT_RUN`/未知值。两条件已由用户二轮拍板（D1 修极性）与 PRD P1–P6 落定。
- **风险清单**（影响 + 应对）：
  - 默认门禁网络/凭据面 flaky → 影响「要不要信默认门禁」；应对：极性修正（外部不可达 ⇒ SKIP，内容不符才 FAIL）。
  - 环境能力缺失时默认门禁仅 SKIP 通过（弱证据）→ 影响下游照抄的理解；应对：SKIP/NOTE 显式计数 + `test:t4:full` 作发布判据 + release notes 明写。
  - `tests/` 不入包 ⇒ 消费者侧 `npm test` 不适用 → 已知副作用；应对：接受并在 release notes / `tests/README.md` 记录，不做容错退 0。
- **技术取舍及理由**：见 ADR `对照过的备选模式`（5 候选含「维持现状」基线 + 不采纳理由）。
- **需 PM 拍板决策点**（均已裁定）：D1 网络面 = 修极性；D2 范围微扩 = 全批准；D3 = 授权 arch 落盘 ADR + 本报告；D4 = 默认不重发 npm；D5 网络中断 = 继续本地实现。

## 二、逐条结构定稿（9 项）

1. **形态** → `test` = `test:agents && test:t4`（全量默认）。无 CI，唯一机械门禁必须默认全量；快循环走具名 `test:agents`。
2. **`prepack`** → `test:agents`。剥离理由是发布路径可用性/时长，不是解环（环已被 `npm pack --ignore-scripts` 阻断）；`prepublishOnly` 承载全量不可取（仅 `npm publish` 触发且需网络）。
3. **默认严格** → `T4_ALLOW_MISSING` 默认 `0`；宽松仅显式 `1`；不加 `test:t4:loose`（不把宽松提升为可见表面）；`--preflight` 标签同步修正。
4. **缺陷 A/B + 第三类假绿** → 汇总改**白名单**（仅 `PASS`/`SKIP` 通过，`BLOCKED`→2，其余含 `MISSING`/`NOT_RUN`/未知→1）；三类参数错误（`--case` 缺值 / `--case` 无匹配 / 裸位置参数）rc=1；第三类 = 用例脚本不以 `t4_exit|t4_skip|exec` 收尾可假绿。
5. **NFR** → 时长接受（3s→≈2min）；「无网络依赖 / 不 flaky」靠极性修正达成：外部不可达/未成功启动/无凭据 ⇒ SKIP/NOTE，仅「拿到真实输出但内容不符」⇒ FAIL。
6. **边界契约** → `tests/` 不入 `files` 的取舍成立；**明确否决**「`test:t4` 加缺套件容错退 0」（即假绿本身）。
7. **递归/副作用** → 无环成立；不建议把 case 02/07 简单移 full（真接口覆盖是默认门禁价值），保留但修极性，full 把 SKIP 变 FAIL 强制真跑。
8. **版本/发布** → v0.18.0（MINOR）正确；npm 默认不重发（消费者侧本就不可用，无收益）；release notes 语义变更进「⚠️ 请留意」，用例数/通过率只进「技术细节」。
9. **ADR** → 需要（跨批次长期契约 + ≥2 候选），落 `docs/adr/2026-10-14-npm-test-gate-scope.md`；实施类内容（本章及以下）下沉本报告。

## 三、清单（必须 / 建议 / 明确不做）

**必须**（落地硬项，对照实际 diff 已满足）：
- `package.json`：`test:agents` = 原 `test` 原文；`test:t4` = `bash tests/t4/run.sh`；`test:t4:full` = `T4_ALLOW_MISSING=0 T4_REQUIRE_FULL=1 bash tests/t4/run.sh`；`test` = `test:agents && test:t4`；`prepack` = `test:agents`。
- `run.sh`/`lib.sh`：默认严格；汇总白名单；三类参数错误 rc≠0；汇总打印 `SKIP: N 例 · M 条` 与 `NOTE: K 条`；`--preflight` 标签修正；`T4_REQUIRE_FULL` 计入汇总层 SKIP（含用例内子项）。
- 契约断言：`scripts.test` 走 `test:t4` 且 `test:t4:full` 含两轴；`scripts.prepack` 不含 t4；`cases/*.sh` 以 `t4_exit|t4_skip|exec` 收尾（第 3 条）。
- 文档同步：`tests/README.md` 运行章节（含安装包内不适用）；`docs/releases/v0.18.0.md`；`docs/tasks-state.md` ⑫ 收口；`.agents/skills/github-flow.md` 阶段 7 发布前置。

**建议**：case 02/07 极性；`--case` 缺值/裸参数校验；可选具名 `release:preflight`；汇总打印每例耗时。（前两项与参数校验本轮已纳入并落地。）

**明确不做**：不拆 `nao-fleet.sh`；不加 CI；不改 `nao-fleet.sh` 功能代码；不改 `package.json files`；不新增宽松脚本；不给 `test:t4` 加缺套件容错；不动既有断言实体（除已批准的 02/07 极性）；默认不重发 npm。

## 四、实施闸门与负控（rd-infra / qa 对照）

- **门禁接缝**：唯一 = `npm test` rc=0（不新增接缝）。
- **负控**：N1 临时移走 `tests/t4/run.sh` → `npm test` rc≠0；N2 向 `.agents/scripts/nao-fleet.sh` 注入守卫缺陷 → rc≠0 且用例 03 FAIL（还原后工作区干净）；N3 `prepack` rc=0 且无 t4 汇总行、无 pi/tmux 调用；**N4** 临时令用例 `exit 77` → 默认 rc=0 / `T4_REQUIRE_FULL=1` rc≠0；**N5** 临时清空 `cases/` → rc≠0（缺陷 A 负控）。
- **SKIP 判据粒度（采纳裁定）**：`T4_REQUIRE_FULL` 的 SKIP 行正则**额外兼容 case 12 实际标记 `SKIP␠␠`（两空格）**，PM 裁定采纳 —— 理由：字面 `[SKIP]` / `SKIP:` 会漏计 case 12 子项，导致 full 判据不完整。留痕于此。
