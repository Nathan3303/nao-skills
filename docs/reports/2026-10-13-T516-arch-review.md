## 二、重点核 2：cleanup 守卫（可证伪）

**候选集合**：`$TMUX` 句柄（`${TMUX%%,*}`）+ 常量 `/tmp/tmux-<uid>/default` + `${TMPDIR:-/tmp}/tmux-<uid>/default`，去重后比对。与 `TMUX_TMPDIR` 完全解耦 ✓（17:11 事故根因已根除：判定不再从 TMUX_TMPDIR 派生）。

**语义**：无 `-S` ⇒ exit 2 单行拒绝 ✓（AC5d 复跑通过）；`-S` 命中候选 ⇒ exit 2 防呆 ✓（AC5e 复跑：真默认 socket 被拒，**我评审会话所在真 server 实测未被波及**）；socket 不存在/陈旧 ⇒ 幂等 rc 0（含 `tmux -S sock ls` 探测 + 残留文件清除兜底，tmux 3.7c 不卸载 socket 文件已实测留痕）✓；kill 失败 ⇒ rc 非 0 + 诊断不谎报 ✓。

**旁路分析**：
- *B1（保守误拒，LOW）*：`$TMPDIR` 变体使「夹具恰好放 `$TMPDIR/tmux-<uid>/default`」的清理被拒（exit 2）。方向安全（宁可拒），代价是显式报错，可接受。
- *B2（信息性边界，LOW）*：生产侧若用自定义 `TMUX_TMPDIR` 启动 server（非标准布局），裸 `env -u TMUX` 调用时守卫无法推知该自定义默认 socket；`cleanup -S <该路径>` 会放行。属不可判定的固有盲点——纪律（夹具 socket 须区别于生产候选）+ 脚本护栏常量双保险是兜底。建议在 help/SKILL 补一句「生产默认 socket 判定覆盖标准布局」的说明（可选）。
- *B3（防御纵深，LOW）*：`-S` 传入符号链接/未归一化路径（`/tmp//tmux-…/default`、symlink）可绕过字符串比对。正常纪律不会产生（夹具 socket 在 $LAB 下、与生产无交集），建议 `readlink -f` 归一化后比对（一行，可选）。
- 脚本护栏（exit 3）与 fleet 内候选**同一常量独立复算**（双保险）✓，且 `rm -rf $LAB` 受 `$LAB` 前缀约束 ✓。

**17:11 事故闭环判定：已闭环。** 根因（TMUX_TMPDIR 参与默认判定 → 真默认 socket 被当非默认放行）在 `prod_sock_candidates` 中不复存在；AC5e 对偶路径改常量；本机实测（含真 server 防呆）通过。
