# T590 文档站 favicon 设计（3 方向 → 用户选 1）

- 状态：待用户选择 · 更新：2026-11-27 · Owner：uiux-designer
- 指针：Issue #256 · 色值基准 `docs/designs/2026-11-16-docs-site.md` §四 · 替换目标 `apps/document/content/public/favicon.svg`（本单不改实现）
- 交付档位：① 结构化文字规格 + 16/32/180 渲染 PNG（`docs/T590-favicon/assets/`）
- 屏幕角色句：这枚图标在 16px 的标签页里帮访客在一排标签中认出 nao-skills；产品定位与安装命令不在这里，它们在首页 Hero。

## 一、信息架构
- 识别场景 4 个：标签页 16 · 书签/历史 32 · iOS 主屏 180 · 深色标签栏（同图形换色）。
- 唯一职责 = 被认出，不承载文字：只允许 1 个形状概念，16px 下不得新增细节；与站点主色同族，不另立品牌色。

## 二、流程
- 识别路径：扫标签行（≤300ms）→ 认出「终端 / 分屏 / 字母」→ 点开；无悬停态、无动效、无点击。失败路径（16px 糊成一团）= 本单要消除的问题，判据见 §三。

## 三、视觉规范
- 画布 32×32，安全区 4–28；最小笔画 / 块边 ≥5.5 单位（16px 下 ≈2.75px，抗锯齿后仍实）。
- 只用实心块或 ≥5.5 的圆头笔画；禁 1px 线、渐变、透明度叠加、内部小字、多层细节。
- 为何不画「七个元素」：16px 下 7 个块间隙 <1px 必糊（实测 2×2 已是可辨下限）⇒ 语义取抽象，不取计数。
- 16px 判据：不看解释能说出「像什么」，缩到 16 后仍有 ≥2 个可辨特征；16/32/180 由同一 SVG 缩放，不另画小尺寸版。

## 四、token
- 亮色 `--nh-accent` #1D4ED8（与站点主色同值，不新增蓝）；暗色 #8FB4FF（沿用现有暗档链接色）。
- 对比：亮 #1D4ED8 / #FFFFFF = 6.3:1；暗 #8FB4FF / #202124 ≈ 7.4:1（均 ≥4.5:1）；背景透明，仅 apple-touch 用实底（§九）。

## 五、状态
- 亮 / 暗：同一路径换 `fill` / `stroke`，`prefers-color-scheme` 媒体查询内联在 SVG（沿用现有占位写法）。
- 16 / 32 / 180 同一几何，180 实底反白；加载失败 / 空 / 无权限：不适用：静态文件，无数据与用户态。

## 六、断点
- 尺寸档而非视口档：16 标签 · 32 书签/任务栏 · 180 主屏；<16 不在支持范围（浏览器不渲染）。
- 16 档是硬闸门：任一方向在 16 不可辨即淘汰（本单据此淘汰三窗格、细笔画、圆拱 n 三个变体）。

## 七、可用性
- 命中区：不适用（浏览器 chrome 渲染，无点击目标）· 识别成本：16px 下 ≤300ms 说出形状，与同行图标并排需 ≥1 个独占特征。

## 八、无障碍
- 图形不承载唯一语义：`role="img"` + `aria-label="nao-skills"`；标签文字始终给名称，图标只作辅助。
- 单色图形，不靠颜色区分；对比见 §四；深色变体必须同形。无动效 ⇒ 无 reduced-motion 分支；无文字 ⇒ 无字号下限问题。

## 九、降级产物
- 档位 ①，附渲染图：`assets/{a-prompt,b-panes,c-n}-16.png` / `-32.png`（`-dark` 为暗底版）· `a-prompt-180.png`。
- `apple-touch-icon`：**要**（180×180，实底 #1D4ED8 + 白图形，iOS 自动裁圆角）；不出则主屏退回截图，观感更差。
- `mask-icon`：**不适用**：Pinned Tab 使用率极低且遮罩丢实心底，维护面 > 收益；可选 `favicon-32.png`（旧 Safari）需要我再同源导出。

## 三方向

- 三案共用外壳：`<svg viewBox="0 0 32 32" role="img" aria-label="nao-skills">` + 内联 `<style>`（亮/暗媒体查询），下列只列几何；完整文件见 `assets/*.svg`（各 ≤10 行，自包含）。
### A 终端提示符 `>_` —— 推荐

- 语义：一切从终端开始 —— 你在 pi 里说一句，小队开工；`>` 是提示符，短块是待输入光标。
- SVG（`assets/a-prompt.svg`，单色 + 暗色媒体查询）：
```svg
<path d="M9 9.5 15 16 9 22.5" fill="none" stroke-width="6" stroke-linecap="round" stroke-linejoin="round"/>
<rect x="20.5" y="20" width="7.5" height="4" rx="1"/>
```
- 16px：3px 笔画 + 3.75×2px 光标，两特征相隔 1.25px；原尺寸实测可读（`a-prompt-16.png`）。
- 暗色：#8FB4FF 同形 · 品牌：同族蓝不改色，开发者一眼可读，不需解释。
### B 四工位分屏（2×2）

- 语义：同一 workspace 里每个角色各占一格（herdr pane 布局）；格子数不承诺等于 7。
- SVG（`assets/b-panes.svg`）：
```svg
<rect x="4" y="4" width="10" height="10" rx="2"/><rect x="18" y="4" width="10" height="10" rx="2"/>
<rect x="4" y="18" width="10" height="10" rx="2"/><rect x="18" y="18" width="10" height="10" rx="2"/>
```
- 16px：每块 5px、间隔 2px，三案里最「实」；代价是像通用网格 / 应用菜单，独占特征最弱。
- 暗色：#8FB4FF 同形 · 品牌：同族蓝，不另立。
### C 字母 N（nao 首字母）

- 语义：品牌首字母，最中性、可长期不换；不解释产品做什么。
- SVG（`assets/c-n.svg`，圆头折线一笔画）：
```svg
<path d="M8 24V8l16 16V8" fill="none" stroke-width="5.5" stroke-linecap="round" stroke-linejoin="round"/>
```
- 16px：3px 笔画 + 满高对角，读作 N 无歧义；但一排字母标里靠形状混，辨识度不如 A。
- 暗色：#8FB4FF 同形 · 品牌：同族蓝；若选此案，建议 site wordmark 的 N 与之同形，避免两张皮。
## 结论与自评
- **推荐 A（`>_`）**：16px 下唯一「形状即含义」的方案（提示符 + 光标），与产品真实入口（pi 命令行）直接对应；B 在 16 退化成通用网格，C 安全但不表意。备选：求稳选 C，强调多窗格选 B。
- 实现交接（rd-fe）：换 SVG 内容、`aria-label` 不动；iOS 用 `a-prompt-180.png`。
- 自评：**PASS**（3 方向齐备，含 16px 实测图、暗色值、附产物结论与推荐）。
