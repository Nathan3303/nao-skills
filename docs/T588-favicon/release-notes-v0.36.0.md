# v0.36.0

- 状态：待核验 · 更新：2026-11-27 · Owner：pm

## 本次更新

这一版把日常交付里最硌人的几处理顺了：**一次任务的文档收进一个目录**、**台账能读了**、**开工前确认过的事有据可查**、**worker 干完活不会再悄悄消失**，另外给文档站首页加了一条会动的产品画面。

## ✨ 更好用了

- **一个任务一个目录**：需求说明、架构评审、决策记录、实现报告、测试复核、发版说明都在同一个目录里，不用再跨几个类别目录拼凑。`docs/` 下新增一份索引，按任务号或版本号一步进到对应目录。
- **台账变短了**：从八百多行降到不到两百行。每个在做的事各占一段，一眼看清「到哪一步」「哪天完成」；完成的自动收走，只留一行索引，历史整体进了归档，照样搜得到。
- **开工确认有据可查**：开工前那张确认卡有了固定形态并留档 —— 隔几天回来也能看到当时确认了什么、谁确认的、发布节奏是什么。
- **文档站首页多了一条产品画面**：Hero 下面嵌了一段真实舰队会话的无声动画，纯装饰、不带任何控件和文字；顺手修好了站点图标线上打不开的问题。

## 🐛 修好了

- **干完活不发回执**：以前任务看起来「消失了」，只能靠人追。现在交付判据改成「PM 侧真的收到回执」，并且 PM 会在交付时刻主动拉一次；拉不到就是明确的超时失败，不会无声无息。
- **多会话同时干活会互相踩**：以前别人切分支会带走你还没提交的改动。现在写明「共享目录里不许切分支，要并行就各开一个独立工作区」，也写清了什么时候不必这么做。
- **文档站图标 404**：线上图标一直打不开，原因是一个文件放错了目录 —— 而构建、外链检查、链接检查三条都说「通过」。现在多了一条检查：页面引用的图标必须在产出里真的存在。
- **文档站两处内容错误**：发版说明里一句称呼不当、体检示例里贴着旧版本的数字。

## ⚠️ 请留意

- **新规矩只管新任务**：2026-11-27 之前的文档留在原目录，冻结只读，既有链接继续有效 —— 升级后你不会看到历史文件被搬动。
- **台账结构变了**：从「进行中」表格改成「批次段 + 状态 + 完成日期」。继续看旧表格会找不到东西。
- **发版前置门禁要选对环境**：有一条真机就绪用例在桌面 app 形态下会失败（根因是首次信任提示导致阻塞，不是变慢）。发布前置请在终端形态的窗口里跑。
- **首页那条动画没有暂停按钮**：它被当作装饰性画面（15 秒、无声、循环）。系统里开启「减少动态效果」时会自动换成静态图。
