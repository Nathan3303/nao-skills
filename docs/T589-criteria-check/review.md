## 一、六条反例 → 规则（原文 / 为什么假 / 机械形态）

1. **R1 聚合轴错** · T579 AC6②「② 值仍为 **1229**，差值 0」，而同一 AC 要求机制文本单源化/搬迁 ⇒ 单源化本身在删旧路径指针，数字必下降 ⇒ 判据恒红，或逼人凑数才绿。形态：Then 含「仍为/不变/差值 0」**且**同块含「单源/收敛/搬/迁移/替换/删除/去重/改名」⇒ 提示。
2. **R2 基数混轴** · T580「53→108 / 108→269 / 176→308」（分子取主台账、分母取并集）⇒ 差值不可解释。形态：同块 `\d+→\d+` 出现 **≥2** 且无「扫描面|基数|同口径|同基数」⇒ 提示。
3. **R3 空集假绿** · T594 worktree gitfile 坏 ⇒ `git ls-files` 拿不到仓库，断言组「扫描面 0 对象」，而 `check` 走「非 git 仓库（跳过）」⇒ 零对象也报绿。形态：同块「扫描面 0|0 个对象|对象为空|列表为空」+「跳过|视为通过|不算失败」⇒ 提示（须先断扫描面 ≥1）。
4. **R4 截断假红** · T594 `cases/06` E2-1 把每行截**前 100 字**再判「有无『截至』标注」⇒ 标注写在第 101 字后假红。形态：「前 N 字|截断|head -c|substring|.slice(0」+ Then 含「含|标注|须」⇒ 提示（不截，或截后只做字面匹配并在块内声明）。
5. **R5 语义隔层** · T587「`innerText` 期望空串」⇒ sr-only 回退句必然进 `innerText`，与「读屏要有回退句」互斥。形态：同一句含 `innerText` + 「空串|为空|空」且不含「可见」⇒ 提示（改用 `clipPath`/`display`/`visibility`，或限定为「可见文本」）。
6. **R6 采样点不稳** · T587「顶边环**行首三点** = 231（亮）/ 48（暗）」⇒ 采样点落在 14px 圆角外/抗锯齿边，实测是 (227,232,239)/(39,49,63)。形态：Then 含「(行首|首)…三点|像素值|= <两位/三位数>（亮）」且无「中点|采样点|坐标|x=|y=」⇒ 提示。

> 我**保留 R6** 但收窄：只判「采样点未声明」这一形态，不判像素值对不对（理由见 §六）。
> 正则速查（与 `/tmp` 原型逐字一致，RD 可直接抄；仍属规格而非实现）：
> R1 `(仍为|仍等于|保持不变|不变|差值\s*0)` ∧ `(单源|收敛|去重|搬迁|搬去|迁移|替换|改写|删除|删掉|改名)`
> R2 `\d+\s*(?:→|->)\s*\d+` 命中 ≥2 ∧ ¬`(扫描面|基数|同口径|同基数|同一批文件)`
> R3 `(扫描面\s*0|0\s*个对象|对象为空|列表为空)` ∧ `(跳过|视为通过|不算失败)`
> R4 `((前|截|取)\s*\d+\s*字|截断|head\s*-c|substring|\.slice\(\s*0)` ∧ Then 含 `(含|标注|声明|须)`
> R5 Then 同句 `innerText` ∧ `(空串|为空|空)` ∧ ¬`可见`
> R6 `((行首|首)[^。]{0,10}(三点|3\s*点)|像素值|=\s*\d{2,3}（亮）)` ∧ ¬`(中点|居中|采样点|坐标|x\s*=|y\s*=)`

## 二、抽取规则（禁静默漏扫）

- **切块**：优先 `### <AC 组>`（PRD 五覆盖分组）；无 `###` 时退化为「整文件一块」。
- **块内定位 Then**：匹配 `^\s*Then\b`（兼容 `然后`）；一块多条 Then 拼接判一次。
- **无 Then 的块显式跳过并计数**：用例必须断言「跳过数 == 0（或等于允许清单）」，否则抽取器失效也报绿。
- **先剥 ``` 围栏**再抽取（与 `check` 既有探针同口径），围栏内示例不参与判定。
