## 本次更新

首页与文档站做了一轮收拾：**整页只留一个实心按钮**，终端示意里那两行「给读者看的解说」换成了真实会出现的输出。同时修掉四处「检查说绿、实际会坏」的地方 —— 包括**刚拉起的会话会被 `close` 静默收掉**，以及**首次在某个目录启动会被信任提示卡住**。

## ✨ 更好用了

- **首页主次清楚了**：整页只保留一个实心按钮（复制安装命令）；「快速开始」变成描边样式的次入口，GitHub 与 npm 变成文字链
- **终端示意更像真的**：「3 个会话窗口逐个亮起（要拉满 7 个…）」这类给读者看的解说，换成终端里真的会出现的输出（`→ pm 接单 · 已派给 arch / rd-fe`、`pi> 想加一个登录页`），并去掉一个永远不会闪的假光标
- **导航不再有两个外链箭头**：GitHub 那一项以前文字里一个 `� ↗`、图标又一个，读屏还会念「上箭头」
- **首页那条动画加载失败时有说明**：现在显示一行「这段录屏没能加载出来 · 刷新可重试」，高度不塌、底边仍是渐隐的

## 🐛 修好了

- **刚拉起的会话会被 `close` 静默收掉**：状态为「空闲」的会话以前直接回收，而「刚启动、还没开工」也是这个状态。现在会拒绝并说明原因，确认无用再加 `--force`；两个终端形态行为一致
- **首次在某个目录启动会被信任提示卡住**：`ensure` 以前只报「就绪门超时」，现在会点明「可能是首次信任提示」并给出一条处置（按 Enter 信任，或预置 `defaultProjectTrust`）
- **站点图标前缀对不上时检查仍然绿**：新增一项检查 —— 图标前缀必须与同页其它资源一致，否则判红
- **「检查器无对象」与「截断副本」会骗人**：这类判据问题现在有静态拦截（见技术细节），并且把今天真正踩过的七种形态写进了写作规范

## ⚠️ 请留意

- **`close` 对「空闲」会话的行为变了**（两个终端形态一致）：以前直接回收，现在需要 `--force`。想保持旧行为可用 `cleanup`（拆场不看忙闲）或加 `--force`
- **发版前置门禁恢复绿**：此前有一条真机用例在这台机器的桌面形态下恒红（首次信任提示），现已修好；严格档 `test:t4:full` 也已通过
- 首页那条动画**失败态会显示一行文字**；正常态仍然只有一个画面，没有任何文字与控件
