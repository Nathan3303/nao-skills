# herdr 后端登记集 —— PRD #96 一期 AC1.1（Issue #96 · `NAO_TEST_TERMINAL=herdr`）
#
# 格式：`<用例编号>  <shared|own>  <到期>  <理由>`
#   shared = 与 tmux 后端**共享**（后端无关：断言面不依赖 tmux / herdr）
#   own    = **本后端专有**（理由必写；到期 = 复核日期，逾期须重判是否仍专有）
# 语义（run.sh 单点实现）：登记集内的用例才跑；**未登记**的用例输出 `[PENDING]` 并点名 ——
#   不得静默 SKIP（PRD §二 目标指标 + 附一裁定①）。登记集非法（未知编号 / 重复 / 列不合法）⇒ rc=1。
# 维护：改本文件必须同步 `tests/README.md`「后端登记集」小节（登记集是 herdr 侧的**唯一**准入清单）。
#
# 为什么不登记 D 类 10 例（09/12/15/19/20/21/22/23/24/25）：它们的断言面建在 tmux 语义上
#   （宿主窗口 / pane 标题契约 / 名册 cwd / `close` 前提 …），**迁移归二期**（PRD §三 范围）且
#   要与生产路径同批改。现在登记只会把 tmux 断言面硬套到 herdr 上、靠 SKIP 掩盖（附一裁定①：不采全绿口径）。
